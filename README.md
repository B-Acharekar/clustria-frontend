# Clustria – Frontend (Next.js + Tailwind)

This is the frontend for Clustria: a personalized, AI-powered cloud storage platform designed for productivity and neurodiverse users.

## 💻 Tech Stack
- Next.js 14 (App Router)
- Tailwind CSS
- TypeScript

## 🚀 Getting Started

```bash
npm install
npm run dev
````

Start editing from `src/app/page.tsx`.

## 📁 Structure

* `src/components`: Shared UI components.
* `src/app`: Routes and pages.
* `src/app/api`: API routes.

## ✅ Features to Build

* Authentication UI
* File manager dashboard
* Smart search
* Reminder and productivity UI
